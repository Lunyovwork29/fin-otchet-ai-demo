# Составление финансовой отчётности с применением ИИ-сервисов

Демонстрационный пример для лекции в колледже. Синтетические данные ТОО «Светлый Дом»
за август 2026 года (валюта — казахстанский тенге, ₸).

**Сайт с демонстрацией:** см. ссылку в описании репозитория / деплой на Vercel.

## Состав проекта

| Файл | Назначение |
|---|---|
| [`01_iskhodnye_dannye.xlsx`](01_iskhodnye_dannye.xlsx) | Исходные «сырые» данные — 23 операции за месяц, с 2 намеренно заложенными ошибками |
| [`00_make_raw_data.py`](00_make_raw_data.py) | Скрипт, которым сгенерирован файл исходных данных |
| [`02_obrabotka.py`](02_obrabotka.py) | Основной скрипт обработки: классификация по счетам, поиск ошибок, баланс и ОПиУ, текстовое пояснение |
| [`03_make_docx.js`](03_make_docx.js) | Скрипт генерации Word-пояснительной записки (docx) |
| [`output/Itogovaya_otchetnost.xlsx`](output/Itogovaya_otchetnost.xlsx) | Итоговый Excel-отчёт: операции с подсветкой ошибок, ОПиУ, баланс |
| [`output/Poyasnitelnaya_zapiska.docx`](output/Poyasnitelnaya_zapiska.docx) | Итоговая пояснительная записка (Word) |
| [`index.html`](index.html), [`style.css`](style.css) | Статическая страница-демонстрация для показа на лекции |

## Заложенные ошибки

1. **Задвоенный платёж** — операция аренды офиса (60 000 ₸, 07.08.2026) внесена в таблицу дважды.
2. **Сумма не соответствует назначению платежа** — зарплата «5 сотрудников по 45 000 тенге»
   указана как 205 000 ₸ вместо расчётных 225 000 ₸.

Скрипт `02_obrabotka.py` находит обе ошибки автоматически и показывает эффект: без проверки
отчёт показал бы прибыль 1 400 ₸ вместо реальных 41 400 ₸.

## Как воспроизвести локально

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install openpyxl pandas
python 00_make_raw_data.py   # генерирует исходные данные
python 02_obrabotka.py       # обрабатывает и строит отчётность

npm install docx
node 03_make_docx.js         # генерирует Word-пояснительную записку
```

Статическую страницу можно открыть напрямую (`index.html`) или через любой статический сервер.
