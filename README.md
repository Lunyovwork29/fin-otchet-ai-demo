# Составление финансовой отчётности с применением ИИ-сервисов

Демонстрационный пример для лекции в колледже. Синтетические данные ТОО «Светлый Дом»
за август 2026 года (валюта — казахстанский тенге, ₸).

**Сайт с демонстрацией:** https://fin-otchet-ai-demo.vercel.app

## Состав проекта

| Файл | Назначение |
|---|---|
| [`01_iskhodnye_dannye.xlsx`](01_iskhodnye_dannye.xlsx) | Исходные «сырые» данные — 23 операции за месяц, с 2 намеренно заложенными ошибками |
| [`00_make_raw_data.py`](00_make_raw_data.py) | Скрипт, которым сгенерирован файл исходных данных |
| [`02_obrabotka.py`](02_obrabotka.py) | Основной скрипт обработки: классификация по счетам, поиск ошибок, баланс и ОПиУ, текстовое пояснение |
| [`03_make_docx.js`](03_make_docx.js) | Скрипт генерации Word-пояснительной записки (docx) |
| [`04_make_site.py`](04_make_site.py), [`index.template.html`](index.template.html) | Генерация `index.html` из шаблона и `output/svodnye_pokazateli.json` |
| [`output/Itogovaya_otchetnost.xlsx`](output/Itogovaya_otchetnost.xlsx) | Итоговый Excel-отчёт: операции с подсветкой ошибок, ОПиУ, баланс |
| [`output/Poyasnitelnaya_zapiska.docx`](output/Poyasnitelnaya_zapiska.docx) | Итоговая пояснительная записка (Word) |
| [`output/svodnye_pokazateli.json`](output/svodnye_pokazateli.json) | Единый источник цифр для docx и сайта |
| [`index.html`](index.html), [`style.css`](style.css) | Статическая страница-демонстрация для показа на лекции (сгенерирована, не редактируется вручную) |

Счета операций — по Типовому плану счетов бухгалтерского учёта Республики Казахстан
(Приказ МФ РК от 23.05.2007 №185): 1350 «Материалы», 3110 «Расчёты по налогам (КПН/СНР)»,
3220 «Обязательства по социальному страхованию», 3350 «Задолженность по оплате труда»,
6010 «Доход от реализации», 7110/7210/7310 «Расходы по реализации / административные /
по вознаграждениям».

## Заложенные ошибки

1. **Задвоенный платёж** — операция аренды офиса (850 000 ₸, 07.08.2026) внесена в таблицу дважды.
2. **Сумма не соответствует назначению платежа** — зарплата «5 сотрудников по 350 000 тенге»
   указана как 1 550 000 ₸ вместо расчётных 1 750 000 ₸.

Скрипт `02_obrabotka.py` находит обе ошибки автоматически и показывает эффект: без проверки
отчёт показал бы прибыль 3 387 000 ₸ вместо реальных 4 037 000 ₸.

## Как воспроизвести локально

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install openpyxl pandas
python 00_make_raw_data.py   # генерирует исходные данные
python 02_obrabotka.py       # обрабатывает, строит отчётность и output/svodnye_pokazateli.json

npm install docx
node 03_make_docx.js         # генерирует Word-пояснительную записку

python 04_make_site.py       # собирает index.html из шаблона по свежим цифрам
```

Статическую страницу можно открыть напрямую (`index.html`) или через любой статический сервер.
Числа на странице и в отчётах всегда берутся из `output/svodnye_pokazateli.json` — при
изменении исходных данных достаточно пересобрать шаги 02 → 03 → 04, руками ничего не правится.
